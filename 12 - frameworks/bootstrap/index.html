Modal pronto
Esse comportamento (abrir/fechar) já vem pronto no JavaScript do Bootstrap, sem precisar escrever nenhuma linha de JS própria.
Particularidade do Bootstrap: tudo que vimos do Bootstrap (navbar, cards, botões, modal, formulário, etc.) já tem visual pronto só com as classes. O trabalho de customização é sobrescrever ou ajustar as variáveis para fugir da "cara padrão".
